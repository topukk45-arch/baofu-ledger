| 原来 → 现在 → 为什么 |
|---|
| 原来（1027-UI7）：每处 `color-mix()` 前面先写一条算好的颜色，以为老 WebView 不认 color-mix 会丢掉那条、退回前面的。 |

## 这轮我自己定的（选了什么、为什么、改回来动哪里）
- **长按阈值 450 毫秒**（你建议的值）：`sheet.js` 的 `LONG_MS`。手机上觉得要按太久就改成 400，太容易误触改成 500。
- **「直接删不确认」只在长按菜单里**：修改账单里的「删除这条记录」照旧先确认。为什么：第一轮你定的是「长按删除只对手动记的账直接删 + 5 秒撤销」，修改账单是另一条路，改了怕你在那里习惯了确认。要两处都直接删：`forms.js` 里 `$('deleteInEdit')` 的点击里给 `deleteRecord` 加 `direct:true`（再把 zZz5、j-refund、zZzZzN 第 6 段里点确认的改成看撤销条）。
- **开发开关关着时的导入记录**：照旧弹一个确认（和修改账单里一样），不直接删——它是导入的，不算「手动记的」。判断「手动记的」= 记录上没有微信 / 支付宝的来源（`src.app`）；和账单对过账的手记（`src.merged`）也算导入的，走四选一。
- **菜单最下面加了「取消」**：要求说三项，「取消」不算一项；按界面规矩「取消 / 返回在最下面」，往下拉、返回键也能关。
- **退款那一笔的菜单没有「再记一笔」**：和单笔详情一样（退款的分类跟着原账单走，照着再记一笔没意义）。
- **从一天面板长按**：菜单是同一个共用面板，所以先收起一天面板，「取消」/ 往下拉 / 删完回到那一天；点「修改」「再记一笔」不回（和从一天面板点进单笔详情再去修改一样）。
- **撤销条的小字**：挂着退款的写「一起删了 N 笔退款」，撤销时一起放回。
- **批量选择模式不弹**：现在 App 里列表没有「勾选几笔」的选择模式（批量改是先搜再改，确认清单那一行是 `.al-row` 不是 `.bl-row`），所以没有要拦的地方；以后加选择模式，在 `detail.js` 里 `jw-longpress` 那个监听里判断一下就行。

## 建议改但没动的
- **账单页整页铺满，统计页、设置页还是一张大卡片（左右各留 10px、带框）**：切页签时内容左右宽度、边框会变（账单页 0–412，另两页 10–402）。这是 1023-C 定的账单页样子，要统一得把统计、设置也铺满，改动面大，没动。
- **统计页丁香主题下收入金额绿字 4.47:1**：差一点点。收入绿 `--c-pos` 是全 App 固定的语义色，改它会牵动所有收入数字，没动；也可以只把丁香这类偏紫的卡片底调浅。
- **统计页分类汇总的行高 34 / 35 不齐（差 1px）**：太小，没动。
- **设置页每一行 51 / 53 / 54 / 67 高不一**：有开关、分段按钮、两行字的行本来就高一些；要统一得定一个最小高，改动面大，没动。
- **整周时副标题「N 笔」和格子里「记了 N 笔」重复**：为了切换时不跳加的。也可以副标题改写别的（比如「日均 x」），你定。
- **一周 / 一天面板换到内容更多的一周会长高一次**（你说的 0.2 秒过渡）：如果想彻底不动，可以打开时把上一周也量进去，代价是面板常常比需要的高。
- **0 笔的那天支出格下面空一行**：为了和别的天一样高留的；也可以写「这天没记账」之类。
