## 这轮我自己定的（选了什么、为什么、改回来动哪里）
- **确认完的一组直接拿掉**（你给了两个选项，没做「挪到底部已确认」）：撤销靠小条，拿掉以后列表更短、要看的都在上面。要改成挪到底部：`search.js` 的 `rgGroups()` 里把已确认的另放一组画在最后。
- **小条浮在面板上、离底 96px**（`.snack.over`，z-index 1034，比面板高、比提示框和文字小面板低），盖住的是面板内容最下面一截，不压「关闭」。手机上要是挡了想看的东西，改 `app.css` 里 `.snack.over` 的 `bottom`。
- **勾掉的那几笔在这组确认完以后回到这组、重新算勾上**：不然剩下的一组按钮是「勾上的 0 笔」点不了。
- **点一笔看详情时面板不关**（详情本来就比面板高一层）：关详情直接回到面板，没有任何动画。详情里点「改分类」时，分类抽屉和成组确认是同一个共用面板（一次只能开一个），会把成组确认换掉；改完关详情，面板照原来滚到的位置回来、不再滑上来一次（`JiwenSheet.open` 新加的 `instant` / `scroll`）。详情里点「修改」去了修改账单，存完面板还在下面、跟着刷新（面板开着时 `render()` 顺手 `rgPaint()`）。
- **按对方改分类也是先关面板再拉分类抽屉**（同一个原因：共用面板只能开一个），选完 / 取消回来不滑上来、位置不变。所以这一步看着是「面板闪一下换成抽屉」，不是叠在上面。要做成叠在上面得让共用面板能开两层，改动大，先没做。
- **「未分类」组展开写「按对方看 ▸」**，按对方的那几行不含退款（退款跟着原单走，原单改了它一起改），所以几行加起来可能比组上写的笔数少一两笔。
- **「交给 AI 按组整理 ›」就是原来那个入口**：整理的是全部待确认分类，不只这一组。
- **问「以后都这样」不看开发开关**（逐条确认、详情里改分类那个 `askCatRule` 要开着才问）：成组确认本身就只在开发开关开着时有。按商品说明归的那几行存成认商品说明的规则（`on:'desc'`，关键词是分组用的那段商品说明，最多 24 个字）。
- **小条上的「撤销」只撤刚才那一次**：后面又有别的改动连着的（比如又在别处改了同一批记录），写一句让去「导入记录」里撤。
- **分类抽屉「＋ 新建」在记一笔、修改、模板、批量改、详情里改分类这几处是当场建**（和分类管理里「添加」一样）：批量改分类时新建了、到确认那一步又取消，新分类留着（空的），批量改的撤销也不删它；只有待确认分类按对方改（走 `aiApply`）的撤销会删没人用的新分类。
- **搜不到才出新建**：搜「果」能搜到「水果」时不出新建；想建「果」得打全一个搜不到的名字。

## 手机上要亲手验证的
1. 待确认分类 → 成组确认：展开、收起、勾掉一笔、点「这组都没问题」，面板不跳、不重新滑上来，滚到中间时位置不变；小条「已确认 … · 撤销」能点、不压「关闭」。
2. 展开后点一笔：开详情；关掉回到面板原来的位置。详情里「改分类」改完关掉详情，面板回来时没有再滑一次。
3. 「未分类 · 支出」：展开按对方的几行；点一行选分类 → 问以后都这样吗（和个人之间的默认「只改这几笔」）→ 面板回来、那几笔不在了；小条「撤销」能撤回；「设置 → 导入记录」里有一行「成组确认」。
4. 分类抽屉：记一笔点「分类」那一行，分类少时最后一块「＋ 新建」；分类多时搜一个没有的名字，「＋ 新建「…」并选上」。
5. 搜一笔：没设条件、有最近搜过时，卡片和「设条件」之间有空隙。
