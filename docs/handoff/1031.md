# 1031-B 打包改成 release 包

按你说的「改 release 包」（你没用过 `chrome://inspect`）。

| 原来 → 现在 |
|---|
| 打包机 `assembleDebug`、发的是 `app-debug.apk` → `assembleRelease`、发 `app-release.apk`（「最新测试版」「上传 APK 产物」「发布正式版」三处一起改） |
| debug 包：手机开着 USB 调试插上电脑，能直接读出 App 里的数据；网页能被电脑上的 Chrome 连上调试（也能读到数据） → release 包两样都关了（Capacitor 默认只在 debug 包里开网页调试） |

- 签名照旧用 GitHub Secrets 里那把 keystore，`android/app/build.gradle` 的 release 签名配置原来就有，代码、App 都没动。
- 包名不变，装着 debug 版的手机直接覆盖安装，数据不丢。
- release 包多跑一道安卓自带的检查（lint），第一次打包要看过没过。

- **预算建议一起放出来**：它不算导入，但导入完成页「按过去几个月设预算」按钮靠它，不放出来那个按钮点了什么都没有。要收回去：`stats.js` 的 `renderBudgetSuggest` 里 `const on=true` 改回读开关（导入完成页那个按钮也要跟着藏）。
- **存储用量一起放出来**：导入、撤销前的自动备份占的就是这块空间，用的人该看得到。收回去：`settings.js` 的 `renderStorageUse` 同上。

## 进账号会读一点导入数据
原来的规矩是「进账号一个导入数据都不读」，那时导入藏着。现在横幅、月初提醒对所有人都开，进账号要读导入记录 `imp_…_i` 那一小块。测试 `s-import-data` 第 8 段改成：只许读导入记录和待处理（最多 2 块），单号表、备份、草稿一块都不许读，读了哪些打印出来（现在只读 1 块 `_i`）；进账号读进来的字数有没有 12 万单号照样一样。
