1025-UX 体验版在 1024-Y 上改交互和界面，不动导入的推荐逻辑、量度和数据（账本原样兼容，装回老版本也能用）。有问题就装「1025-UX 起点」（= 1024-Y 原样的包，签名一样，直接覆盖安装，账本不动）。

## 账单页、统计页
- 月份浮条又能左右拨着切月份了：中间一个深色选中框，横着拨、松手停好就切到框里那个月；点一下照旧能切。不会再像以前那样打开 App 自己跳到最早的月份
- 回到顶部的箭头从浮条里拿出来，变成浮条右上方单独一个圆钮（滑过一屏才有，和浮条一起出来、一起收）
- 一周详情和当日详情合成一个面板：顶上一行「整周 一 二 … 日」，点哪个就地换，不再一层盖一层；左右滑换周 / 换天，内容跟着手指走；从整周点进某一天，按返回键先回整周

## 记一笔
- 存好以后不再弹「记账成功」，底部浮一条小条「已记下 吃饭 12.00」+「再记一笔」「补备注」，4 秒自己收；列表里新记的那一行闪一下
- 选了分类会自动带上它平常的收支（以前几乎都记成支出的就选支出），不用每笔都点「支出」
- 分类、收支都选好时，金额键盘的大按钮直接写「保存」，点了就存
- 修改账单保存后也有小条「已改好 …」，那一行闪一下

## 搜一笔
- 「最近搜过」在往下看列表时收成一行，不再一直盖着列表；回到顶上自己展开

## 外观和设置
- 默认主题色从金黄换成雾松青（就是「恢复默认」那个颜色，和启动画面一样）；选过主题的人不受影响
- 登录页就能换主题色，写明进去以后在「设置 → 外观」也能改；外观里的预设都写上了名字
- 设置页重新分组：记账（管理分类、常用模板）→ 外观和偏好 → 存档管理 → 云备份 → 账户；不起作用的「滑动提示」先藏起来

## 修复
- 共用的底部面板会残留上一个面板的点击、滑动（比如一周详情开过两次再左右滑，内容会被盖成别的周）
