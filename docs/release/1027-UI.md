1027-UI 体验版在 1025-UX 体验版上只改界面，不动导入、推荐、量度和数据（账本原样兼容）。有问题就装回「1025-UX 体验版」（签名一样，直接覆盖安装，账本不动）。

## 主题色
- 按钮就是你选的颜色，不再一律压深：浅色也能当主题（天青就是淡天青），按钮上的字自动配同色的深字或浅字，保证看得清；按钮和底色太接近时加一道细边
- 预设换成 24 个，分红赭、青绿、蓝紫、墨灰 4 组，一组一行 6 个，色块下写名字，选中的有一圈环和勾；默认（恢复默认）是雾松青
- 原来的豆沙粉、橄榄绿、素墨米不再是预设，选过的人颜色和名字都不变
- 自己调的颜色有名字了（比如「近天青」「雾竹青」），下一行一句短评；设置「外观主题」、外观弹窗、登录页三处都写，拖色条时跟着变
- 选色面板放开了深浅的范围，浅色也能选
- 「恢复默认」挪到「自定义主色」那一行右边

## 一周 / 一天面板
- 打开时定好高度，切天、切整周、左右滑、换周时面板顶边不动；换到内容更多的一周才慢慢长高
- 「左右滑动看前一天、后一天」只在前 3 次打开时写
- 0 笔的那天、今天还没过完时，不再写「比本月日均少」
- 「当天净剩」挪到两格下面单独一行

## 看着别扭的地方
- 一周和一天来回切时，下面的内容不再上下跳
- 统计页、设置页来回切时，标题不再上下跳
- 底栏没选中的页签字、「不计」「往来」的金额、「支出」小标签，原来字太淡，改深了
- 卡片圆角、一周里每天那一行的高度和别处统一
- 选色面板下面那句说明固定两行，拖动时面板不跳
