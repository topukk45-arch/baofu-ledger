在「1027-UI3 体验版」上做了界面收敛的第一轮：只统一样子，不改功能，不动导入、推荐、量度和数据（账本原样兼容）。有问题就装回「1027-UI3 体验版」（签名一样，直接覆盖安装，账本不动）。

## 汇总块
- 「大字金额 + 一行说明」的地方只留一种样子：浅底、不画边框、圆角 16。列表卡才有细边，两种靠有没有边框分开
- 统计页「当月支出 | 当月收入」两格合成一块：支出大字在左、收入在右，下面一行「比上月同期多花 / 少花 · 本月净剩」
- 一天面板：两格和「当天净剩」合成一块，「支出 · N 笔」，下面「净剩 x · 比本月日均多 y」；分类改成一根叠起来的条 + 下面的小胶囊（这一轮还不能点）
- 一周面板：两格合成一块，「日均（N 天）」在右，柱子画在块里
- 预算总览改成汇总块，预算外、年度预算挪到下面一张卡
- 日子页置顶的那个日子，从主题色实心大卡片改成浅底

## 页头
- 账单、统计、设置的标题都是 32px 大字，在同一个高度。统计页标题改成「10月」大字 + 小字年份（点了照旧选年月），「收支 | 预算」挪到标题右边
- 日子、搜一笔的标题 20px，下面不再画线；一天、一周面板的标题也是 20px

## 切换和设置页
- 两到四个选项的切换（统计页「收支 | 预算」、饼图「支出 | 收入」、设置里的几个开关）都换成浅底滑块，高 40
- 「整周 一 … 日」照旧是深色选中块，高度改成 40，和滑块对齐
- 设置页每组合成一张卡，一行 48 高；「默认进入页面」的四个选项放到名字下面一整行

## 字、行、圆角
- 浅色字收成两档：说明文字一档，时间、序号、百分比浅一档；24 个预设下两档在页面底、卡片、面板底上都看得清（对比 ≥ 4.5:1）
- 支出红、收入绿、接近上限的黄、「不计」「往来」的灰稍微压深了一点，24 个预设下都看得清
- 一行的行 48 高、两行的行 54 高；圆角只留 9 / 12 / 16 三档
- 列表里的金额不再加粗（一周里每天、分类汇总这些），汇总的大字和「合计」照旧粗

## 空状态
- 搜不到、这天没记账、没设预算、没有日子：都是一个图标 + 一句话 + 一个按钮，按钮直接带你去下一步（放宽条件 / 给这天补一笔 / 设个预算 / 添加日子）
