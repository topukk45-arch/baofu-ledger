1027-UI5 体验版在「1027-UI4 体验版」上做了界面收敛的第二轮：只改界面和点了去哪，不动导入、推荐、量度和数据（账本原样兼容）。有问题就装回「1027-UI4 体验版」（签名一样，直接覆盖安装，账本不动）。

## 点分类直接看这一类的账
- 统计页饼图旁的分类：点一行去搜一笔，条件是这个月 + 支出（或收入）+ 这个分类；「其余 N 类」带上这几类
- 预算页的分类行：点了去搜一笔（这个月 + 支出 + 这个分类），不再原地展开；改预算挪到预算总览的「改预算 ›」
- 一天面板的分类小胶囊：点了去搜一笔（这一天 + 这个分类）
- 带进来的条件在搜一笔里浅底标出来，点 ✕ 照样能去掉；按 ‹ 或返回键回到原来那一页，月份、页签、滚到的位置、一天面板都还在

## 统计页
- 日历按花得多少分四档深浅：按这个月记过支出的日子排，花得最少的最浅、最多的最深；只有收入的日子不着色。日历下面一行图例「花得少 ▢▢▢▢ 花得多」
- 饼图旁「较上月 ↑12%」改成「▲12%」，不再红绿

## 预算条
- 去掉了「今天」那根竖线：条的底色上一段斜纹表示「到今天的平均进度」，实际花的叠在上面
- 预算页的分类条、预算总览、统计页的预算入口三处都是这个画法；接近上限的条换成更深一点的黄

## 账单页
- 这个月有分类超预算时，月份下面一条红色提示「吃饭 本月超预算 224.00 · 看预算 ›」，点了去预算页；几类超了写「吃饭等 2 类超预算」
