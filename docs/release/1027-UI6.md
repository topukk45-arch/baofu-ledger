1027-UI6 体验版在「1027-UI5 体验版」上做了界面收敛的第三轮：只改交互，不动导入、推荐、量度和数据（账本原样兼容）。有问题就装回「1027-UI5 体验版」（签名一样，直接覆盖安装，账本不动）。

## 长按一笔
- 账单列表、搜一笔的结果、一天面板里，按住一笔不动约半秒，弹出一个小菜单：顶上是这一笔，下面「修改 / 再记一笔 / 删除」
- 点一下照旧进详情；按着的时候手指挪了、页面滚了，就不弹
- 「再记一笔」：分类、金额、备注、收支照这一笔填好，时间是现在，打开记一笔让你看一眼再存（不会直接存）；退款那一笔没有这一项
- 从一天面板里长按的，点「取消」或删完回到那一天

## 删除
- 长按菜单里删自己记的账：不再问一遍，直接删，底部一条「已删除「午饭 −15.00」 撤销」，5 秒内点「撤销」原样放回（时间、顺序都不变，挂着的退款一起回来）
- 5 秒内又删了一条，前一条就算删了，提示换成新的那条
- 导入的账照旧先问四种删法（只删这条 / 删掉以后也不导入 / 改成不计 / 撤销整批导入）
- 修改账单里的「删除这条记录」照旧先确认一下
