## 待确认分类（开发开关里）
- 成组确认的面板不再一点就关掉重开：展开 / 收起、勾掉一笔、「这组都没问题」都在面板里原地变，滚到哪还在哪
- 确认完的一组从列表里拿掉，顶上「共 N 条」跟着减；底部小条「已确认 购物 · 支出 141 笔 · 撤销」；全部确认完才自动关
- 分组按「分类 + 收支」：「未分类 · 支出 300 笔」「未分类 · 收入 30 笔」分开，不再把付给别人的和别人转来的混在一起
- 展开后的每一笔和账单页一样：支出 − 、收入 + 绿色，带时间和来源；点一笔是看这笔的详情（能改分类），关了回到面板原来的位置；左边的勾选框才是勾选
- 「未分类」组没有「这组都没问题」了：展开后按对方一行「某某 · 104 笔 · 共 x 元 ›」，点一行选个分类就整行改好，改完问「以后这个对方都记成 X 吗」（转账、红包、对方带 * 的默认只改这几笔）；卡片上的主按钮是「交给 AI 按组整理 ›」
- 按对方改的那一下自动备份，底部小条能撤销，「导入记录」里也有一行「成组确认」能撤销

## 分类抽屉
- 选分类时能直接新建：搜不到的名字下面「＋ 新建「水果」并选上」；分类少、没有搜索框时「全部」最后一块「＋ 新建」
- 名字和已有分类一样就直接选已有的，不会重复建；记一笔、修改、模板、批量改都能用；导入页里的选分类照旧不能新建
