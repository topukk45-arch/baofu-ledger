**β 贝塔版**：日常记账照常用；账单导入经过 10-20、10-21 两轮真账单实测改了一遍，比 α 版准得多，入口还在开发开关里。版本号写 1021-T25，代码和体验版 1021-T25（提交 446a82e）一样（发行用的那次提交只多了打包脚本和这份说明），还没合进 main。

## 新功能
- **账单导入一步一步来**：选好文件后分几步确认：核对笔数 → 退款和转账 → 分类 → 金额要你看一眼 → 总览；没事的步骤不出现，每步写清还剩几件没定，导到一半退出能接着来（最多留 24 小时）
- **看得到每一笔**：凡是写了「N 笔 / 共 x 元」的地方都能点开：按时间排、每页 50 笔，点一笔看完整详情（支付方式、来源），能单独改分类；明细按分类一类一行、默认收起，几百笔也不卡
- **分类更准**：按对方一组选一次分类，选过的记成规则；从你的账本历史里学；推荐理由写成一句话，标「有把握 / 拿不准」；「文化休闲」拆成「游戏」「会员订阅」；平台下不同的店不再互相带偏；付给个人的钱（扫收钱码、转账）不照抄支付宝写的「商业服务」；网咖不再算餐饮
- **退款更准**：支付宝商品说明写「退款」的都认成退款、挂上原单；同一个人 3 天内转回来的一部分钱当作那笔的退款；全额退款的一对两条都跳过
- **只对账**：存档里有手记时，可以只补进漏记的几笔；勾了原单，挂在它上面的退款一起补进；点一行能看详情
- **导完以后**：结果页四格能点开看是哪几笔；去看统计、设预算以后能回到结果页；导入记录里能「看结果」「重新分类」「交给 AI 再检查一遍」，导错了整批撤销
- **待确认分类**：拿不准的照推荐入账，账单页顶上「待确认分类 N 条」一点就筛出来，改了分类就去掉标记

## 界面
- 记一笔 / 修改照新排法：时间、金额、收入 / 支出、最近常用的 4 个分类，下面一张列表卡（分类、统计、常用、备注）
- 金额用 App 自己的数字键盘（照微信转账，长按连删 / 连输），备注、名字这类点了弹文字小面板；设置里能换回系统键盘
- 「统计口径」改叫「统计」：计入 / 不计 / 往来
- 所有弹窗都是从下面滑上来的底部面板，往下拉、按返回都能关；第二层不再加深
- 日子页、自定义主色、分类管理、常用模板改了样子；打开 App 先出上次的首屏，不再闪一下

## 怎么打开账单导入
设置页最底下的版本号，2 秒内连点 5 次，打开「导入（开发中）」。不打开就看不到，也不影响平时记账。建议先在新存档里试导。
