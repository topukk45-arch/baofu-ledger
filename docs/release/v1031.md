**记问 1031**：第一个把账单导入正式放出来的版本。平时手记，月底把微信、支付宝账单导进来，自动和手记对上、不重复；拿不准的分类交给你自己用的 AI 按组整理。数据只存在手机里，App 不联网。

下载下面的 `jiwen-1031.apk` 安装。没有自己的账单也能试：仓库 [`docs/samples/`](https://github.com/topukk45-arch/baofu-ledger/tree/main/docs/samples) 里有一个月的虚构微信、支付宝账单。

## 新功能
- **账单导入正式放出来**：「设置 → 存档管理 → 导入微信 / 支付宝账单」，不用再连点版本号打开开关；新建账号时会问一句「导入账单 / 从零开始记」；在微信、文件管理器里「用记问打开」账单文件直接进导入
- **导入更省事**：核对完笔数可以直接「导入」，想细看再「逐项看看」；大额先问一句算不算收支，记住你的选法；按天对账，手记和账单金额对得上的天直接按手记为准
- **分类更准、要你看的更少**：规则能认商品说明；从你的手记备注里学；记住你「几笔合成一条手记」的对账习惯；新分类至少 3 笔才建
- **待确认分类**：拿不准的照推荐先入账，账单页顶上「待确认分类 N 条」；能逐条确认、按分类成组确认（一组一下、能撤销）、一键按新规则重新推荐，或者交给 AI 按组整理：AI 的建议按「原分类 → 新分类」分块列出，整块勾选
- **看得到账单原文**：导入的每一笔详情里能看账单原文，单号、全文一键复制；零碎扣款、收款这类几笔合成的一条，列出是哪几笔
- **删导入的记录**分「只删这条」「删掉，以后也不导入」「改成不计」「撤销整批」
- **单号表能存一份到云盘**，换手机后再导同一段账单不会重复

## 界面
- 账单页按月 → 周 → 天分层：周是一条带 7 根小柱子的分隔线，天是卡片；月份浮条左右拨着切月；没记账的日子一行细字，点了补一笔，也能标「这几天没花钱」
- 一周 / 一天合成一个面板，左右滑换周换天
- 新的「搜一笔」：日期、金额、收支、分类、统计口径、备注多选组合，记住最近搜过的，搜到的能批量改
- 统计页：日历带周合计、和上月同期比、总结余算式、全部记录的分类汇总、预算进度带时间斜纹、按过去几个月给预算建议
- 24 个预设主题色（苏芳、天水碧、秘色、松烟墨……），也能自己调，自己调的颜色会起中文名；不管选什么颜色，字都保证看得清
- 记完一笔底部小条「补备注 / 再记一笔」，长按一笔能修改、再记一笔、删除（手记的删了 5 秒内能撤销）
- 新图标（篆书「記」）；打开 App 先显示上次的首屏，不闪

## 修复
- 老版本安卓 WebView（常见于模拟器）上几处颜色不显示
- 打开 App 会自己跳到最早的月份
- 搜一笔结果页条件卡压着列表
- 共用底部面板残留上一个面板的点击、滑动

## 兼容
- 安装包改成 release 包（以前是 debug 包）：插上电脑也读不出 App 里的数据。签名、包名不变，可以直接覆盖安装 1021 β 和之前的版本，账本不动
- 旧存档、旧备份文件都能直接用
- 拿自己的账本试导入之前，建议先在「设置 → 导出存档」备份一份；导入本身每次都会先自动备份、能整批撤销
